### [Riko Next](https://github.com/sanokiyo1029-sys/riko-next)

A local-first AI companion you can talk to and interrupt mid-sentence.
- **Stack:** `gpt-oss:20b` through Ollama, Faster-Whisper for speech in, GPT-SoVITS for speech out.
- **Fast:** the first word arrives in about 0.3 s, and she starts speaking before she has finished thinking.
- **Safe tools:** tool calls are permission-gated, with no shell access.
- **Memory you control:** each memory keeps its evidence, and you can inspect, correct or delete it.

It's written in Python and JS under the MIT license.
